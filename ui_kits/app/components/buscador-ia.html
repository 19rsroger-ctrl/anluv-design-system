Búsqueda multimodal con IA

El buscador interpreta texto, voz e imagen. La capa de IA entiende lenguaje natural («una laptop para estudiar que no pase de dos mil soles»), transcribe la voz con Web Speech API (es-PE) y recibe fotos para identificar el producto. Estructura y estilos extraídos de assets/anluv.css + assets/app.js. En móvil el panel se convierte en un bottom sheet anclado al borde inferior (patrón nativo de comercio móvil) y el input sube a 16 px para evitar el zoom de iOS.

Buscador completo (funcional)

.searchbox + .search-panel — enfoca el input para abrir el panel

    Arrastra una foto del producto o toca para elegirla

    La IA la identifica y te muestra productos parecidos.

    Resultado de la última búsqueda (evento anluv:buscar)

    Todavía no has buscado nada. Prueba con texto, voz o una foto.

    Cómo interpreta la IA cada modo

    Reglas de interpretación (demo local, sin backend)
    • Texto: entiende intención y presupuesto en lenguaje natural («laptop para diseño que no pase de cinco mil») y extrae la categoría y el tope de precio.
    • Voz: transcribe con Web Speech API en es-PE y aplica la misma interpretación de texto. Si el navegador no la admite, ofrece escribir o WhatsApp.
    • Imagen: recibe una foto del producto y la IA la identifica para mostrar coincidencias; en esta demo confirma la recepción y busca la categoría general.
    Historial persistente: localStorage("anluv:busquedas"), máx. 5 entradas compartidas entre todas las cajas de búsqueda.
